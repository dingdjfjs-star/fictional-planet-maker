# 虚构行星工坊 —— 板块/大气/洋流驱动的类地行星生成器

从零参数生成一颗虚构类地行星:自定义**板块运动**(欧拉极/汇聚-离散-转换边界/热点链)、**大气环流**(哈德里环宽度随自转缩放/信风西风带/ITCZ 摆幅/季风)、**洋流**(Sverdrup 流函数等值线+西边界暖流/东边界寒流/赤道流系/环极流),自动产出**山脉、流域、沙漠、季风气候分区**,输出 GeoJSON 矢量、气候分区设定、城邦文明背景,并配 **Cesium 三维渲染预览**。

内置**3 套参数差异巨大的星球方案**,并配套 33-34 项地理逻辑自检(自检→发现漏洞→修复→再检的完整迭代留痕见 [迭代日志.md](迭代日志.md))。

## 快速开始

```
启动预览.bat        ← 双击:启动本地服务器(端口 8961)并打开浏览器
```

或手动:

```
cd 预览 && node server.js    →  http://127.0.0.1:8961
```

预览页功能:星球切换 / **🛠 行星工坊(输入一句中文描述 → 解析成参数 → 生成专属行星并保存,可改参数反复加工,🎲换骨架探索不同地形)** / 地形-气候-构造三种贴图 / 板块·河流·湖泊·洋流·气候·季风·城邦·商路图层开关 / 点击城邦弹出文明背景卡 / `?debug=1` HUD(实体数/错误)/ `?atmo=1` 开启大气。

工坊识别的描述要素(例:"一颗自转很慢的沙漠星球,一整块超级大陆被大裂谷劈开,四季几乎不存在,昼夜60小时,火山密布,名叫赤漠"):昼夜小时数或自转快慢、倾角度数或四季强弱、陆地/海洋几成、超级大陆/双陆/破碎群岛、板块数、火山多寡、冰封/炎热/湿润/温和、极地大陆、行星名字。解析结果会给出人话版摘要,所有参数都可微调后重新生成。

## 重新生成数据

```bash
node 工具\run-all.js        # 生成三颗行星 + 自检
node 工具\generate.js 烬壤   # 只生成一颗
node 工具\validate.js        # 只跑自检(FAIL 时退出码 1)
node 工具\geomcheck.js       # 几何体检(自触环/反子午线/对跖段, Cesium 兼容性)
```

生成零依赖(纯 Node),每颗约 4 秒,seed 固定可复现。

## 自查与迭代(亮点)

`工具/validate.js` 对每颗星做 33-34 项检查:陆地占比命中、河流贴陆率、**西边界流方向必须向极**、**赤道流向西**、**雨林只在低纬/冰原只在极地/沙漠不在赤道**、季风纬度、城邦落陆+间距、商路贴陆、期望现象对照(每颗星的设计意图)等。

迭代过程中抓出并修复的真 bug(完整记录见[迭代日志.md](迭代日志.md)),包括:

- **Float32 距离场 + double 堆键** → Dijkstra 永不收敛(ulp 级伪改进);
- **强制碰撞/张裂的欧拉极符号反了**(向量三重积 (n̂×m)×m=−n̂ 推导漏负号);
- **大陆板块间走廊被判定为海洋** → 碰撞造山带沉入海底(陆桥修复);
- **大陆内部陆性指数饱和到 1.0** → 分位阈值失效、造山被压扁;
- **moistureDecayDeg 参数语义用反**(衰减尺度越大内陆越湿);
- **构造抬升把陆地占比挤出目标**(海平面重定基准修复);
- **Cesium 兼容四连**:自触环、DP 直线坍缩、反子午线跳变、RHUMB 细分竞态。

## 约定与说明

- GeoJSON 坐标使用行星等距圆柱投影(经纬度即图上坐标),Cesium 以同尺寸椭球渲染;
- Cesium 1.144 本地化于 `预览/vendor/cesium`(零外网依赖),避开该版本已知三类渲染停摆写法(见 `~/.agents/skills/cesium-twin-builder`);
- 端口 8961(避开 3000/5433/5173/8940/8931)。
